Mutalyzer 2 history
-------------------

The git history before 2019 is that of the ``mutator`` module of
Mutalyzer 2, kept for reference. This package is a new implementation
and shares no code with it. The authors of the Mutalyzer 2 module were:

- Jeroen F.J. Laros
- Martijn Vermaat
- Gerben Stouten

::
